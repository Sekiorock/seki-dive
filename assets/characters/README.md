| ファイル名 | 中身 | 大きさ |
| --- | --- | --- |
| stand-normal.png | 立ち絵（通常） | 1024×1536 px、背景透過のPNG |
| stand-smile.png | 立ち絵（笑顔） | 1024×1536 px、背景透過のPNG |
| stand-surprise.png | 立ち絵（驚き） | 1024×1536 px、背景透過のPNG |
| face.png | 顔アイコン | 256×256 px |
