# ⑥ セキオ電子ロック（denshi）

高校化学「電池と電気分解」のワールド。プレイヤーは電子1個になります。
どの教科書を使っていても学べるように、特定の教科書のページや問題番号は画面に出しません。
いまの版は **denshi v0.6.0** です（8クエスト。電池・電気分解・工業の全範囲と、まとめの紙芝居）。

## クエスト

目次は8つ。それぞれのクエストの中で、小さな「話」が順に進みます（上の点の列は、話ごとに少し間があきます）。

| 番号 | 名前 | 中身の話 |
| --- | --- | --- |
| 0 | 自由電子の海 | 金属の中の自由電子 → イオン化傾向 → イオン化列の坂 |
| 1 | 電池のしくみ | 亜鉛の旅立ち（ダニエル電池）・泡になる旅（ボルタ電池）・濃度の作戦会議 |
| 2 | 実用電池めぐり | 電池図鑑・両極が白くなる（鉛蓄電池）・4人で酸素を迎えに（燃料電池）・層間ホテル（リチウムイオン電池） |
| 3 | 電位の登山と陰極の門番 | 電位の登山（標準電極電位）・陰極の門番 |
| 4 | 陽極の門番と電気分解 全制覇 | 陽極の門番・電気分解 全制覇 |
| 5 | ファラデーの計量 | ファラデー計量官（Q = it、F）・直列電解槽 |
| 6 | 電気分解の工業 | 膜の関所（イオン交換膜法）・陽極泥の宝探し（銅の電解精錬）・水のない世界（溶融塩電解） |
| 7 | 電子むかしばなし | 紙芝居。電気自動車・蓄電池・水の電気分解・燃料電池バス・電池の再資源化を、昔話ふうの寸劇でたどる（約3分） |

- 話の変わり目まで進むと、そこを覚える。途中でやめても、目次の「続きから」で再開できる。
- 印はクエストごと（銀印＝そのクエストの全問を一発で正解）。金印の試練は、中身の話から問いを集めた5問。
- ヒヤマは、中身の話の数だけ増える（例：話が3つのクエストの銅印は 100 × 3）。
- v0.4 までの記録は自動で引きつぐ（まとめた中身をすべて取っていた印だけが残る）。記録の形は `v: 2`、キーは `c0`〜`c6`。
- コードの中では、話は `PQ.q0`〜`PQ.q16`、まとめたクエストは `QUESTS.c0`〜`c6`（`chapter()` で作る）。

問いのうち「金属・数・電池を変えた問い」は、その場で作るので毎回変わります。

## この版でできること

- 3Dの電池を、指でなぞって見回す。2本指で拡大。舞台をタップすると光の花が咲く
- 出来事が起きるたびに、反応式の帯（クエスト0はイオン化列）が1項ずつ埋まる
- **印**：銅印＝クリア、銀印＝全問を一発で正解、金印＝「金印の試練」に合格
- **金印の試練**：銀印を取ると挑戦できる。数や金属や条件を変えた問いが5問（毎回変わる）。5問すべて一発正解で金印
- **ヒヤマ**：印を初めて取ったときに支給（銅100・銀150・金250。まとめて取れば合計）。2回目からのクリアは20。所得税と1日の上限は、ほかのワールドと同じ（`shared/economy.js`）
- **学習の記録**：問いごとの回答数・一発正解の数・選ばれた誤答、最初の予測。本人の記録（`users/{uid}/worlds/denshi`）に保存され、管理画面の「電子ロック」タブで全員分を集計して見られる
- 「↩ 戻る」で、いまの段階の最初からやり直す。日本語／英語。⛩ で中央広場へ。♪ でBGMの入／切

ヒヤマの支給と記録は、広場と同じ場所（GitHub Pages）で開いたときだけ働きます。`index.html` を単体で開いたときは、この端末の中の印だけが残ります。

## v0.4.0：電気分解編（クエスト9〜13）

| 番号 | 名前 | 内容 |
|---|---|---|
| 9 | 陰極の門番 | 陰極で電子を受け取るもの（Cu²⁺・Ag⁺／H⁺／水） |
| 10 | 陽極の門番 | 陽極で電子を失うもの（Cu・Ag の電極／Cl⁻・I⁻／OH⁻／水） |
| 11 | 電気分解 全制覇 | 水溶液と電極の組み合わせ（毎回変わる）で、両極の変化を答える |
| 12 | ファラデー計量官 | Q = i × t、F = 9.65×10⁴ C/mol、電子の物質量から変化量を求める |
| 13 | 直列電解槽 | 直列の2つの電解槽。どの電極にも同じ物質量の電子が流れる |

- 装置の灯りが「電源」に変わり、左が陽極（＋側）、右が陰極（−側）。
- 問いに正解すると、その電極の反応（析出・気体の発生・電極が溶ける）が背景で動き続ける。
- 水溶液の一覧は `LY`、電極は `ELN`、反応式は `CAT`・`AN` にまとめてある。

## v0.3.1 で直したもの

- **3 濃度の作戦会議**：早送りは問いに答えるまで続く。Cu²⁺ が減るほど銅板に銅が析出する。Zn²⁺ と SO₄²⁻ が素焼き板を行き来する。電子が流れなくなる場面では、導線の電子が止まり、灯りが消える
- **4 電池図鑑**：電池ごとに装置が入れかわる（電極の札と色、電解質、起電力に合わせた灯りの明るさと電子の速さ）。放電と充電は電子の流れの向きで見せ、二次電池は充電の動き、一次電池は使い切りの動きを出す
- **5 両極が白くなる**：質量の説明を「Pb が PbSO₄ になるから SO₄ の分」「PbO₂ が PbSO₄ になるから SO₂ の分」に
- **6 4人で酸素を迎えに**：装置を「水素の通り道｜負極｜電解質｜正極｜酸素の通り道」の並びにした。最初から、水素・H⁺・電子・酸素・水の流れが動き続ける。電子は水素分子の中から出発する
- **7 層間ホテル**：電極を厚い層の重なりにし、電子は層の中から出発。泊まっている Li⁺ を増やした。放電容量は、メーターが減るようすで説明する
- **8 電位の登山**：正解のとき、2つの金属の高さに線を引き、そのあいだを矢印で結んで電位差を示す

## 世界のルール（全クエスト共通）

1. 電子は金属と導線の中だけを動ける。水溶液へは出られない
2. 界面では、イオンに「乗り移る」（還元）か、原子から「放り出される」（酸化）
3. 水溶液の中は、イオンに憑依して動く
4. 色：酸化・負極・陽極＝淡い珊瑚色、還元・正極・陰極＝淡い水色

## 数値や文字を変えたいとき

`index.html` 1枚で動きます。

- 数値：`<script>` のいちばん上の `CONFIG`（進む速さ、音量、ヒヤマの額 `reward`、金印の試練の問いの数など）と、その下の `G`（装置の大きさ）
- クエストの中身：`QUESTS`（段階ごとの進行 `stages`、装置 `world`、反応式の帯 `eq`）。金印の試練の問いは `pairAsk`・`molAsk`・`battAsk`・`pbAsk`・`fcAsk`・`mahAsk`・`emfAsk`・`FACTS`。実用電池の表は `BATT`、標準電極電位は `E0`
- 色：`COL`（3Dの色）と、`<style>` のいちばん上の `:root`（画面の色）
- 文字：`T`（左が日本語、右が英語。必ず両方に書く）
- キャラクターの色：`CHARS`。絵は `charSVG()`
- 音：`snd`（音階は `YO`、BGMは `schedule()` と `drone()`）
- カメラの向き：`VIEWS`
