# ⑥ セキオ電子ロック（denshi）

高校化学「電池と電気分解」のワールド。プレイヤーは電子1個になります。
どの教科書を使っていても学べるように、特定の教科書のページや問題番号は画面に出しません。
いまの版は **denshi v0.2.0** です。

## クエスト

| 番号 | 名前 | 内容 | 問い |
| --- | --- | --- | --- |
| 0 | 自由電子の海 | 金属の中の自由電子 → イオン化傾向 → イオン化列の坂 → 金属を変えた練習（毎回ちがう組み合わせ） | 8問 |
| 1 | 亜鉛の旅立ち | ダニエル電池。酸化 → 導線 → 還元 → SO₄²⁻ に憑依して素焼き板を通る | 6問 |
| 2 | 泡になる旅 | ボルタ電池。酸化 → 導線 → H⁺ に乗り移って水素の泡になる | 6問 |

## この版でできること

- 3Dの電池を、指でなぞって見回す。2本指で拡大。舞台をタップすると光の花が咲く
- 出来事が起きるたびに、反応式の帯（クエスト0はイオン化列）が1項ずつ埋まる
- **印**：銅印＝クリア、銀印＝全問を一発で正解、金印＝「金印の試練」に合格
- **金印の試練**：銀印を取ると挑戦できる。数や金属や条件を変えた問いが5問（毎回変わる）。5問すべて一発正解で金印
- **ヒヤマ**：印を初めて取ったときに支給（銅100・銀150・金250。まとめて取れば合計）。2回目からのクリアは20。所得税と1日の上限は、ほかのワールドと同じ（`shared/economy.js`）
- **学習の記録**：問いごとの回答数・一発正解の数・選ばれた誤答、最初の予測。本人の記録（`users/{uid}/worlds/denshi`）に保存され、管理画面の「電子ロック」タブで全員分を集計して見られる
- 「↩ 戻る」で、いまの段階の最初からやり直す。日本語／英語。⛩ で中央広場へ。♪ でBGMの入／切

ヒヤマの支給と記録は、広場と同じ場所（GitHub Pages）で開いたときだけ働きます。`index.html` を単体で開いたときは、この端末の中の印だけが残ります。

## v0.1.2 で変えたもの

- **戻るボタン**：クエストを6つの段階に分け、段階の最初へ戻れるようにした。「これはモデルです」からタイトルへも戻れる。一度まちがえた記録は戻っても消えない（銀印は全問一発正解のまま）
- **見やすさ**：3Dの舞台を藍色の夜にした（明度の対比で、淡い色の粒が光って見える）。まわりの紙は生成りの和紙のまま
  - 玉の縁の手前を少し濃くして、ぼかしたままでも形がわかるようにした
  - スポットライト：注目している所のまわりだけ明るく残し、ほかを少し沈める
  - 導きの光：次に見る所へ光が飛ぶ。目印の輪：操作を待つ場所で輪が脈打つ
  - 文字とボタンの色を濃くし、札を大きくした
- **和の光の世界**：青海波の床、広がる水紋、舞う花びら、月と星と山のちぎり絵、光るものは加算合成。舞台をタップすると、その場所に光の花が咲いて鈴が鳴る

## v0.1.1 で変えたもの

- **見た目**：和紙のちぎり絵 × 淡い光の世界。色は淡いパステルで統一。原子・電子・イオンは輪郭をぼかした玉。器や金属板は角を丸くした
- **キャラクター**：案内役ミコト、亜鉛の精エン、銅の精アカネ（その場で描くアニメふうの絵。表情は ふつう・笑顔・おどろき・しょんぼり）。電子にも小さな顔
- **音**：すべてその場で合成する和風の電子音（箏・鈴・水琴窟・拍子木・小さな太鼓）と、陽音階のBGM
  - 正解：上がっていく箏と鈴。続けて正解するほど高く華やかになる。花びらが舞う
  - 不正解：低い太鼓と、半音でぶつかる濁った箏を小さく短く。画面が一瞬くすんで揺れる
- 教科書のページ・問題番号の表示をなくした

## 世界のルール（全クエスト共通）

1. 電子は金属と導線の中だけを動ける。水溶液へは出られない
2. 界面では、イオンに「乗り移る」（還元）か、原子から「放り出される」（酸化）
3. 水溶液の中は、イオンに憑依して動く
4. 色：酸化・負極・陽極＝淡い珊瑚色、還元・正極・陰極＝淡い水色

## 数値や文字を変えたいとき

`index.html` 1枚で動きます。

- 数値：`<script>` のいちばん上の `CONFIG`（進む速さ、音量、ヒヤマの額 `reward`、金印の試練の問いの数など）と、その下の `G`（装置の大きさ）
- クエストの中身：`QUESTS`（段階ごとの進行 `stages`、装置 `world`、反応式の帯 `eq`）。金印の試練の問いは `pairAsk`・`molAsk`・`FACTS`
- 色：`COL`（3Dの色）と、`<style>` のいちばん上の `:root`（画面の色）
- 文字：`T`（左が日本語、右が英語。必ず両方に書く）
- キャラクターの色：`CHARS`。絵は `charSVG()`
- 音：`snd`（音階は `YO`、BGMは `schedule()` と `drone()`）
- カメラの向き：`VIEWS`
