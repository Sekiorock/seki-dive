# セキオダイブ（seki-dive）

高校化学「第4章 溶液」のシリアスゲーム。いまの版は **v1.2**：**home v1.2.0**、**hydration v1.2.0**（① セキオ溶解ロック）、**crystal v1.2.0**（② セキオクリスタロック）、**freeze v1.2.0**（③ 凝固点コーカーロック）、**colloid v1.2.0**（④ セキオロッコロイド）です。

## v1.2 で足したもの

- 施設の名前：ロック国庫・ロック銀行・ロック物販・ロック呉服屋
- **ロック物販**（`shared/items.js`）：ワールドごとのヒント券3段階（弱・中・強）、ステージ4から先に必要な「通行手形」、レバレッジ券（×1.2〜×10。クリアで報酬が倍、失敗・途中でやめると「基本の報酬 ×（倍率−1）」の罰金）、ゲージお守り・目盛り拡大鏡・予算追加券・霧よけのお札・報酬上限アップ券・幸運のお守り
- **図鑑の減税**：図鑑の追加ページ1ページにつき、所得税と消費税が 1% 下がる（5ページまで。`shared/economy.js` の `ZUKAN_RELIEF`）
- **ロック呉服屋**：13人を追加（物質の擬人化。絵は `shared/charart.js` がその場で描く）。テッペイ（鉄）は 30,000 ヒヤマで、テッペイでいる間は税も罰金もかからない。衣装は「種類10 × 色17」になり、1度買えば、だれにでも着せられる（前の版の色違いは、そのまま引き継ぐ）
- セキオ溶解ロック：クリアして次のステージが開いたあと、タイトルにすぐ出るように直した（開いたステージを選んだ状態にする）

## v1.1 で変えたもの

- 全体の難易度を下げた（くわしくは各ワールドの README.md）。セキオ溶解ロックの難易度の作り直し、セキオクリスタロックの問題のアニメとヒントの小窓、凝固点コーカーロックの各ステージの公式アニメ、セキオロッコロイドの選択肢を消すヒント
- ワールドの名前を変えた：① セキオ溶解ロック ② セキオクリスタロック ③ 凝固点コーカーロック ④ セキオロッコロイド

## v1.0 で足したもの・直したもの

- **キャラクターの名前**：どの場面でも、キャラクターの顔・立ち絵の下に名前の札。セリフの頭にも名前（例：タケヒロ「……」）
- **映えの演出**（`shared/glow.js`）：セキオロッコロイドと同じ「和風ゲーミング」の映えを、広場と①〜③にも。ステージが進むほど豪華になる（1 浮かぶ灯籠 → 2 光の粒 → 3 ネオンの鳥居と月 → 4 光の柱 → 5 光の和柄の輪 → 6 桜・雪・泡 → 7 光の文字と金箔 → 8 オーロラ）。広場は4つのワールドの進み具合で豪華になる。数値は各ワールドの `src/config.js` の `GLOW`
- **対戦の賞金のずれを防ぐ**：通信が一瞬切れた人がいると、端末ごとに順位の見え方がずれて、賞金の合計が参加料の合計をこえることがあった。最初に結果を出した端末が部屋に結果を書き、全員がそれを使うようにした（4つのワールドすべて）。**`database.rules.json` を Firebase のコンソールに貼り直してください**（`rooms/…/result` を書けるようにした）
- ホームの操作の説明が、画面の左右ではみ出していたのを直した

## この版でできること

- 夜の3D広場「セキオロック中央広場」を、指でなぞって見回す（v0.5 から、角ばったゲーム画面風＋和柄のサイバー和風。床・壁・屋根・柱に亀甲・青海波・麻の葉・格子・瓦の模様、提灯・石灯籠・看板・光の粒）
- 東西南北の4つの門（セキオ溶解ロック、セキオクリスタロック、凝固点コーカーロック、セキオロッコロイド）
- 上の帯：顔アイコンとニックネーム、残高、QRボタン、「日本語｜EN」の切り替え
- QRボタン：参加用のQRコードを画面いっぱいに表示
- 初めて起動したとき：言語の選択 → ニックネームの入力 → 広報官キタローによる国の説明と開国交付金 → 広場へ
- 門をタップするとアバター選択の画面へ。①〜④のワールドへ入れる。くわしくは各フォルダの README.md
- 9人の仮の絵と衣装の色違い：`assets/characters/` （差し替え方はそのフォルダの README.md）
- 通貨ヒヤマ：Firebase に保存（準備をしていなければ、この端末だけ）。上の帯の右に残高（押すと通帳）
- 銀行（通帳）、呉服屋（キャラクターの解放・衣装の色違い）、道具屋（ヒント券などのサービス）。買い物には消費税がかかり、国庫に入る
- 中央の政府庁舎：上に国庫の残高が浮かぶ。タップすると掲示板（国庫・税率・お知らせ）
- 政府からのお知らせ：重大発表は画面が暗くなり中央に出る。本人への罰金は画面の縁が紅に、交付金は金に光る
- 画面下の「施設と門の一覧」から、すぐに施設や門へ移れる
- **管理画面**（`admin.html`、先生だけ）：概要、生徒の残高と通帳の点検、授業交付金・特別交付金・罰金、お知らせ、税率などの設定、ワールドの開閉、対戦の可否、任意の税（住民税・資産税）と長者番付、国庫の記録
- 先生が閉じたワールドの門は、灰色になって入れなくなる

## Firebase の準備

`FIREBASE_SETUP.md` を見てください。準備をしなくても、この端末だけで動きます（管理画面は Firebase の準備が必要です）。
先生のアカウントの作り方は、その 6 にあります。
`database.rules.json` は、Firebase のコンソールに貼り付けるルールです（GitHub Pages では使いません）。

## 公開のしかた（GitHub Pages）

1. GitHub で `seki-dive` という名前のリポジトリを作る
2. このフォルダの中身をアップロードする（`index.html` がいちばん上に来るように）。
   GitHub の画面からは、1回に100個までしか上げられないので、配られた zip を順番に上げる
3. Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして Save
4. 数分後に `https://ユーザー名.github.io/seki-dive/` で開ける

パソコンで `index.html` をダブルクリックして開くと、文字のファイルが読めずに動きません。必ず GitHub Pages の URL で開いて確かめてください。

## 数値を変えたいとき

- ホームの数値（3Dの大きさ、明るさ、カメラなど）：`home/src/config.js`
- お金の数値：`shared/economy.js` のいちばん上の `SETTINGS`（Firebase の `settings` に値があればそちらが優先。home v0.5 から管理画面で変えられる）、`shared/characters.js` の `UNLOCK_PRICE`・`COSTUME_PRICES`
- 色：`shared/theme.js`（伝統色とネオンの色）と `shared/base.css` のいちばん上
- QRコードで配るURL：`home/src/config.js` の `PUBLIC_URL`（空なら開いているページのURLを自動で使う）
- 画面の文字：`shared/i18n/ja.json` と `shared/i18n/en.json`（必ず両方に書く）

## 最初からやり直して確かめたいとき

ブラウザの「履歴とサイトデータの消去」でこのサイトのデータを消すと、初めて起動したときの流れからやり直せます。
Firebase につないでいるときは、別の人として扱われます（開国交付金がもう一度出て、国庫が減ります）。
