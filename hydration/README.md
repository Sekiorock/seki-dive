# ① ハイドレーション・ビート（hydration）

いまの版は **hydration v0.1.0** です。ホームの北の門（①）から入ります。

## この版でできること

- 3Dの空間：1本の道を、奥の霧の中から Na⁺ と Cl⁻ が飛んでくる。手前に判定リング、その下にプレイヤーの水分子
- 左のボタン「O（δ−）」：陽イオン（Na⁺）に水の O を向ける。右のボタン「H（δ+）」：陰イオン（Cl⁻）に水の H を向ける
- 判定：PERFECT ±50 ms、GREAT ±90 ms、GOOD ±130 ms。向きが逆なら「逆向き」でミス
- 正しく叩くと、6個の水分子が正しい向きで取り囲み、水和イオンになって漂っていく。背景の NaCl の結晶が少しずつ小さくなる
- ステージ1「極性のプレリュード」（90 BPM、約90秒）。曲はその場で合成。コンボが続くと音が厚くなる
- 一時停止（右上のボタン、言語の切り替え、ほかのアプリに移ったとき）、結果の画面
- コンボ30ごとに、選んだアバターの立ち絵が出る

## 数値を変えたいとき

`src/config.js`（判定の幅、点数、ノーツの速さ、音量など）。譜面は `src/charts.js`。
