# ① ハイドレーション・ビート（hydration）

いまの版は **hydration v0.8.0** です。ホームの北の門（①）から入ります。

## この版でできること

v0.8 で足したもの（対戦：タイマン）：
- タイトルの「対戦」から、部屋を作る（4桁の番号が出る）か、番号で入る。2人そろったら、部屋を作った人が開始する
- 2人で同じ曲（部屋を作った人がタイトルで選んだ曲と難易度）を同時に演奏し、曲の終わりのスコアが高いほうの勝ち
- 10コンボごとに、相手に妨害が1つ飛ぶ：色消し（次の8ノーツが補助輪なし）・無極性の群れ（見送るノーツが4個割り込む）・
  濃霧（8秒間、ノーツが判定リングの直前まで見えにくい）
- 画面の左上に、相手の顔・スコア・ゲージ・コンボ。結果の画面は順位とスコアだけ（間違いの内訳は本人だけ）
- 参加料 100 ヒヤマが賞金になり、勝負税 10% を引いて勝った人へ（引き分けは半分ずつ）。
  始まってから抜ける・30秒以上つながらない・60秒以上操作しないと、罰金 200 ヒヤマ（金額は管理画面で変えられる）
- 対戦できるのは、管理画面の対戦の設定が「いつでも」のとき、または「授業中のみ」で先生が「授業を始める」を押したとき
- 対戦は Firebase につながっているときだけ（部屋の仕組みは shared/room.js。ほかのワールドの対戦でも使う）
- v0.6・v0.7（ヒヤマを Firebase へ・政府の管理画面）は、ホームの版ですでにできているので、番号をとばした

v0.5 で足したもの：
- クリアの報酬（ヒヤマ）：やさしい 30／ふつう 80／むずかしい 200。その難易度で初めてクリアしたときは2倍。
  所得税が引かれ、1日の上限がある（どれも先生が管理画面で変えられる）。結果の画面に税引き前・所得税・手取りを出す。練習曲には報酬なし
- ショップ（演出）：正しく水和させたときの演出を買って使う（桜吹雪 500／金の輪 1,000／雷光 1,500／星くず 3,000。消費税つき）
- ホームの道具屋で買った品が使えるように：ヒント券（ふつう・むずかしいで、1曲だけ補助輪1の文字）、
  苦手問題の練習券（間違えた溶質だけの練習曲）、図鑑の追加ページ（図鑑の「特集ページ」を1ページ開く。全5ページ）
- 言語の切りかえで、結果の画面やショップも描き直すように

v0.4 で足したもの：
- ステージ5「ヘキサンの夜」（110 BPM）：途中で溶媒がヘキサンに交代。プレイヤーはヘキサン分子になり、
  左右のボタンが中央の「なじむ」1つにまとまる。無極性分子（ヨウ素、ナフタレン、ベンゼン、四塩化炭素）は「なじむ」、
  イオンや糖は見送る
- ステージ6「溶解性マトリクス」（125 BPM）：全種類＋溶けにくい結晶。曲の途中で水とヘキサンが4回入れかわる
- 結果の画面に、間違いの種類ごとの回数と一言の解説。いちばん多かった間違いを先頭に出し、その溶質の3D模型を回して見られる
- 「この解説を図鑑に保存」と、タイトルの画面の「図鑑」：分子の模型（21種類。水とヘキサンでの正しい入力つき）と、保存した解説

v0.3 で足したもの：
- ステージ1〜4（極性のプレリュード 90 BPM／結晶ほどき 100 BPM／ハイドロキシ・グルーヴ 105 BPM／電離のブレイク 115 BPM）
- 画面の上の「水和ゲージ」。曲の終わりに 70% 以上ならクリア。前のステージをどれかの難易度でクリアすると、次のステージが開く
- 曲と難易度ごとの最高点とクリアの記録（本人の情報に保存。Firebase につながっていれば、ほかの端末でも続きから）
- タイミング調整の画面：メトロノームに合わせて8回たたくと、その端末の音とタップのずれを測って補正する。
  初めて遊ぶ端末では最初に出る。タイトルの画面の「タイミング調整」からやり直せる。補正はその端末にだけ覚える

v0.2 までのもの：

- 3Dの空間：1本の道を、奥の霧の中から溶質が飛んでくる。手前に判定リング、その下にプレイヤーの水分子
- v0.2：カメラを高く・遠くから見下ろす形に変え、次の粒子、その次の粒子まで見えるようにした
- 左のボタン「O（δ−）」、右のボタン「H（δ+）」。溶質の種類ごとの正しい入力：
  - 陽イオン（Na⁺、K⁺、Cu²⁺）：左／陰イオン（Cl⁻、I⁻、OH⁻、SO₄²⁻）：右
  - -OH をもつ分子（エタノール）と極性分子（NH₃、酢酸）：左右を同時に押す（0.09 秒以内）
  - 糖（グルコース、スクロース）：同時押しが -OH の数だけ続く
  - HCl：左（H に O を向ける）のすぐあとに、できた Cl⁻ に右
  - 無極性分子（ヘキサン、ベンゼン、CCl₄、I₂、ナフタレン）と溶けにくい結晶（AgCl、BaSO₄、CaCO₃）：押さずに見送る
- 判定：PERFECT ±50 ms、GREAT ±90 ms、GOOD ±130 ms。向きが逆なら「逆向き」、同時押しが片方だけなら「片側だけ」、
  見送るものを押したら「誤水和」でミス
- 難易度と補助輪：やさしい（補助輪1：色と「陽イオン」などの文字。続けて押すところを減らし、ゆっくり）、
  ふつう（補助輪2：色と ＋／− の記号だけ）、むずかしい（補助輪なし：化学式と白黒の模型だけ、速い）
- 曲：ステージ1「極性のプレリュード」（90 BPM）と、練習曲「ノーツ・パレード」（96 BPM、すべての溶質が順番に出る）
- 正しく叩くと、溶質に合わせた水和の演出（イオンは水分子6個、-OH には3個、HCl は H₃O⁺ + Cl⁻）
- 一時停止、結果の画面（間違いの種類ごとの回数）、コンボ30ごとのアバターの立ち絵

## 数値を変えたいとき

`src/config.js`（判定の幅、難易度、水和ゲージ、タイミング調整、カメラ、点数、音量など）。譜面は `src/charts.js`、溶質の一覧は `src/notes.js`、
分子の模型は `src/models.js`。
