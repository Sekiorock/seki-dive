# ① ハイドレーション・ビート（hydration）

いまの版は **hydration v0.3.0** です。ホームの北の門（①）から入ります。

## この版でできること

v0.3 で足したもの：
- ステージ1〜4（極性のプレリュード 90 BPM／結晶ほどき 100 BPM／ハイドロキシ・グルーヴ 105 BPM／電離のブレイク 115 BPM）
- 画面の上の「水和ゲージ」。曲の終わりに 70% 以上ならクリア。前のステージをどれかの難易度でクリアすると、次のステージが開く
- 曲と難易度ごとの最高点とクリアの記録（本人の情報に保存。Firebase につながっていれば、ほかの端末でも続きから）
- タイミング調整の画面：メトロノームに合わせて8回たたくと、その端末の音とタップのずれを測って補正する。
  初めて遊ぶ端末では最初に出る。タイトルの画面の「タイミング調整」からやり直せる。補正はその端末にだけ覚える

v0.2 までのもの：

- 3Dの空間：1本の道を、奥の霧の中から溶質が飛んでくる。手前に判定リング、その下にプレイヤーの水分子
- v0.2：カメラを高く・遠くから見下ろす形に変え、次の粒子、その次の粒子まで見えるようにした
- 左のボタン「O（δ−）」、右のボタン「H（δ+）」。溶質の種類ごとの正しい入力：
  - 陽イオン（Na⁺、K⁺、Cu²⁺）：左／陰イオン（Cl⁻、I⁻、OH⁻、SO₄²⁻）：右
  - -OH をもつ分子（エタノール）と極性分子（NH₃、酢酸）：左右を同時に押す（0.09 秒以内）
  - 糖（グルコース、スクロース）：同時押しが -OH の数だけ続く
  - HCl：左（H に O を向ける）のすぐあとに、できた Cl⁻ に右
  - 無極性分子（ヘキサン、ベンゼン、CCl₄、I₂、ナフタレン）と溶けにくい結晶（AgCl、BaSO₄、CaCO₃）：押さずに見送る
- 判定：PERFECT ±50 ms、GREAT ±90 ms、GOOD ±130 ms。向きが逆なら「逆向き」、同時押しが片方だけなら「片側だけ」、
  見送るものを押したら「誤水和」でミス
- 難易度と補助輪：やさしい（補助輪1：色と「陽イオン」などの文字。続けて押すところを減らし、ゆっくり）、
  ふつう（補助輪2：色と ＋／− の記号だけ）、むずかしい（補助輪なし：化学式と白黒の模型だけ、速い）
- 曲：ステージ1「極性のプレリュード」（90 BPM）と、練習曲「ノーツ・パレード」（96 BPM、すべての溶質が順番に出る）
- 正しく叩くと、溶質に合わせた水和の演出（イオンは水分子6個、-OH には3個、HCl は H₃O⁺ + Cl⁻）
- 一時停止、結果の画面（間違いの種類ごとの回数）、コンボ30ごとのアバターの立ち絵

## 数値を変えたいとき

`src/config.js`（判定の幅、難易度、水和ゲージ、タイミング調整、カメラ、点数、音量など）。譜面は `src/charts.js`、溶質の一覧は `src/notes.js`、
分子の模型は `src/models.js`。
