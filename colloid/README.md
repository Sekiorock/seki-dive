# ④ コロイド・ミスト（colloid）

いまの版は **colloid v0.1.0** です。ホームの門（④）から入ります。摩周湖をモデルにした霧の湖を、1人で探検するパズルです。案内役は湖の神主です。

## v0.1 でできたこと（エリア1〜3）

- エリアに入ると、その道具を受け取り、まず「しくみ」を2ページで見る（「しくみ」ボタンでいつでも見直せる）
  ① 動く絵（光の通り道／水分子がぶつかる／袋からイオンだけが出る）と、やさしい説明
  ② **粒の大きさのものさし**（分子・イオン 〜10⁻⁹ m ＜ コロイド粒子 10⁻⁹〜10⁻⁷ m ＜ 泥・沈殿）。どのエリアでも同じものさしを見せる
- エリア1「霧の入江」（光の鈴）：チンダル現象
  - 1-1 3つの水たまり（名前は伏せてある）を鈴で調べ、光の通り道が見えるもの（デンプン水）を選ぶ
  - 1-2 霧の中に光を当て、光の筋が見えるわけ（水滴が光を散らす）を選ぶ → 橋が現れる
  - 1-3 セッケン水・食塩水・うすめた牛乳から、光の通り道が見えるものを全部選ぶ
- エリア2「揺らぐ浅瀬」（限外の眼鏡）：ブラウン運動と粒の大きさ
  - 2-1 眼鏡でのぞくと、光の点が不規則に動く。そのわけを選ぶ → 正解すると、のぞき窓に水分子も描かれる
  - 2-2 分子・イオン、コロイド粒子、泥の粒を小さい順に
  - 2-3 食塩水・水酸化鉄(III)の液・泥水を眼鏡でのぞき、ブラウン運動が見えるものを選ぶ
- エリア3「セロハンの関所」（セロハンの袋）：透析
  - 3-1 イオンだけを出す袋を選ぶ（セロハン／ポリエチレン／ろ紙）
  - 3-2 外へ出るものを全部選ぶ（H⁺、Cl⁻）
  - 3-3 袋を水につけて「待つ」「外の水を替える」をくり返し、イオンを 5 以下に。硝酸銀で外の水が白くにごる（AgCl）ことも確かめられる → 鍵が光り、門が開く
- まちがえると、神主が理由を一言で返す（選んだものに合わせて）。調べずに選んだときは「まず調べよう」
- のぞき窓（右上の丸）：限外の眼鏡で見たようす（何も見えない／光の点のブラウン運動／沈む大きな粒／透析）
- 報酬：エリアを抜けるごとに 100 ヒヤマ（はじめてのとき）
- 3D：夜明け前の霧の湖と森、外輪山、中島。水たまり・杯・霧の橋・浅瀬の飛び石・関所の門とたらい

## 数値を変えたいとき

`src/config.js`（謎の中身と答え、液体の性質、透析の割合、報酬、のぞき窓の粒の数など）。文字は `shared/i18n/ja.json`・`en.json` の `cl.` で始まるもの。
