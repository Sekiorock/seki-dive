# キャラクターの画像

キャラクターごとのフォルダに、次の4つの画像を置きます。今入っているのは、AIが作った仮の絵（線画の簡単なシルエット）です。

| ファイル名 | 中身 | 大きさ |
| --- | --- | --- |
| stand-normal.png | 立ち絵（通常） | 1024×1536 px、背景透過のPNG |
| stand-smile.png | 立ち絵（笑顔） | 1024×1536 px、背景透過のPNG |
| stand-surprise.png | 立ち絵（驚き） | 1024×1536 px、背景透過のPNG |
| face.png | 顔アイコン | 256×256 px |

衣装の色違いは、キャラクターのフォルダの中の色の名前のフォルダ（例 `minato/gunjo/`）に、同じ4つのファイル名で置いてあります。どの色を置くかは `shared/characters.js` の `COSTUMES` に書いてあります。

同じファイル名・同じ大きさの画像で上書きすれば、プログラムを直さずに差し替えられます。立ち絵は、足もとを画像の下の端にそろえてください（3Dの広場では、画像の下の端が地面になります）。

## v1.2：13人の追加と、だれでも着られる衣装

ショウ・ヒロナ・ユウキ・ヒロキ・アリス・マリネ・タカマサ・シゲル・ミク・アスカ・シホ・カズエ・テッペイ（特別）の絵は、PNG ではなく `shared/charart.js` がその場で描いています（髪型・紋・いつもの衣装は `LOOKS`）。
衣装（種類 × 色）を着た姿も、同じくその場で描きます。上の9人は、いつもの衣装のときだけ、このフォルダの PNG を使います。
本物の絵に差し替えたいときは、そのキャラクターのフォルダに4つの PNG を置き、`shared/charart.js` の `LOOKS` でそのキャラクターに `png: true` を足してください。
