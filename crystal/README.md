# ② クリスタル・ラボ（crystal）

いまの版は **crystal v0.2.0** です。ホームの東の門（②）から入ります。

## v0.2 で足したもの（気体の実験台・濃度の実験台、カメラ、本物に寄せた結晶）

- カメラ：1本指でなぞると回る、2本指で広げる・せばめると寄る・引く、2本指で動かすと平行に動く、ダブルタップで元に戻る。
  画面の上の視点のボタン（固体：全体／結晶／グラフ、気体：全体／水の中／圧力計、濃度：全体／液の中）で、見たいところへなめらかに移る。
  はじめは全体（溶解度曲線の板まで）が入る引いた画角。下の操作盤は「▼ たたむ」で小さくでき、3Dを広く見られる
- 結晶の形を本物に寄せた：KNO₃ は断面がほぼ六角形で先のとがった細長い柱、KCl は少しくもった立方体、
  NaCl は面の中央が階段状にくぼんだ立方体（骸晶）、CuSO₄·5H₂O は本物の格子の角度（α 97.6°、β 107.2°、γ 77.3°）でゆがんだ、青く透きとおった平たい六面体。
  どれもガラスのように周りの光を映す
- 気体の実験台：気体（H₂、N₂、O₂、CO₂、空気、HCl）、圧力 1.0〜3.0×10⁵ Pa、温度 0〜60℃、水 1〜10 L。
  溶けた物質量・質量・体積（その圧力のもとと、標準状態）を表示。水の中に溶けた分子の粒、圧力計とピストン、
  「栓を開ける」で 1.0×10⁵ Pa に下がり、溶けきれなくなった気体が泡になって出る。空気は N₂：O₂ ＝ 4：1 で分圧ごとに計算。
  HCl は「ヘンリーの法則に従わない」と注意を出し、計算しない
- 気体の溶解度の値は `src/config.js` の `GAS_TABLE`（1.013×10⁵ Pa で水1 L に溶ける物質量、0・20・40・60℃）。教科書の表1と違うときは書きかえる
- 濃度の実験台：溶質（NaCl、グルコース、硫酸）、溶質の質量、溶媒（水）の質量、溶液の密度を動かすと、
  質量パーセント濃度・モル濃度・質量モル濃度の3つのメーターが同時に動く（計算の式と数値つき）。メスシリンダーの液の高さは体積に合わせて変わる
- 発見を8つ追加（全部で17）：ヘンリーの法則／温めると気体は溶けにくい／栓を開けると泡／空気の溶け方／ヘンリーの法則に従わない気体／
  密度で変わるのはモル濃度だけ／うすい水溶液ではほぼ同じ／量を変えても濃度は同じ

## v0.1 でできたこと（固体の実験台と自由実験）

- 工房の主はカリン。タイトルの画面で「実験台」と「モード」を選ぶ（「注文」「精製」は v0.3 で開く）
- 3D のビーカー：ホットプレートの上のビーカー、水、温度計、底にたまる結晶、うしろに溶解度曲線のパネル。
  画面をドラッグすると、ビーカーのまわりを少し回って見られる
- 動かせるもの：溶質の種類、温度（0〜80℃）、水の質量（50〜300 g）、溶質の質量（0〜200 g）
- 溶質：硝酸カリウム（針の形）、塩化カリウム・塩化ナトリウム（立方体）、硫酸銅(II)無水物・五水和物（青いひし形）、
  混合物（KNO₃ 9：CuSO₄·5H₂O 1）
- 溶解度は教科書の表（0〜80℃、10℃ごと）を直線でつないで計算。溶けている量・結晶の量・溶液の水・状態（不飽和／飽和／過飽和）を画面に出す
- 硫酸銅(II)は五水和物として析出する計算（結晶が水を持っていくので、溶液の水も減る）。五水和物を溶かすと、結晶の水が溶媒に加わる
- 曲線のパネルに、いまの状態を点で表示（不飽和は青、飽和は黄、過飽和は赤）
- 過飽和：熱い溶液を 1.5 秒以内に 15℃以上いっきに冷やすと、35% の確率で結晶が出ないまま「過飽和」になる。
  「種結晶を落とす」を押すと、一気に結晶が育つ
- 発見（9種類）：全部とけた／溶け残り／冷やして析出／温めて溶けた／過飽和／種結晶／水和物の水／NaCl は温度でほとんど変わらない／混合物から KNO₃ だけ。
  初めて見つけたとき、発見報酬 20 ヒヤマ（所得税・1日の上限はほかと同じ）。「発見」ボタンで一覧（まだのものはヒントだけ）

## 数値を変えたいとき

`src/config.js`（スライダーの範囲、過飽和の起こりやすさ、発見報酬、結晶の数、気体の溶解度の表、カメラの動きなど）。固体の溶解度の表は `src/solubility.js`、結晶の形は `src/crystals.js`。
